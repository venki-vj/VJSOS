# VJSOS Metrics — Monthly Reports

> Monthly status reports and KPI tracking.

## Purpose

Monthly reports track progress against OKRs and KPIs, capture lessons, and surface blockers early.

## Cadence

- **Due:** Last Sunday of each month
- **Review:** Async (session log + GitHub issue)
- **Output:** `metrics/MonthlyReports/YYYY-MM.md`
