# VJSOS Kernel — ExecutionCycle

> The immutable rhythms of execution.

## Daily (ref [[docs/sop/DAILY]])
- Morning: load [[docs/MASTER_CONTEXT]], set 3 Phase 1–2 tasks
- Blocks: Phase 1 → Phase 2 → Phase 3 (slow)
- Evening: session log [[sessions/YYYY-MM-DD-DayN.md]], commit

## Weekly (ref [[docs/sop/WEEKLY]])
- Mon: PLAN (3–5 sprint goals, phase-classified)
- Tue–Thu: EXECUTE
- Fri: REVIEW + RETRO (metrics, lessons, process updates)
- Sat: IMPROVE (update SOPs, ADRs)
- Sun: Rest / learning

## Monthly (ref [[docs/sop/MONTHLY]])
- Last Sunday: metrics review, strategic health, process audit
- Produces: [[metrics/MonthlyReports]]

## Quarterly
- Last Sunday of quarter: OKR review, roadmap refresh
- Produces: [[metrics/QuarterlyReports]]

## Triggers & Gates
- Every cycle requires REVIEW before next PLAN.
- No cycle starts without updated [[docs/CHANGELOG]].
- Kernel changes require formal process (see [[kernel/README]]).
