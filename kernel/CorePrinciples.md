## The Seven

1. **Build capability before buying capacity** — systems and skills first; hardware/hire only when it unlocks blocked work.
2. **Originality is law** — everything is original, licensed, or cleared; no derivative IP, ever.
3. **Child safety first** — a non-negotiable gate on all children's content.
4. **Trust over virality** — evergreen, honest packaging beats manipulative engagement.
5. **Phase-aware development** — Phase 1→2→3→4, in order; defer 4.
6. **Systems before heroes** — a documented, repeatable system beats individual brilliance.
7. **Knowledge is compound interest** — docs, ADRs, and lessons accumulate into permanent value.

## Authority
These are immutable. Changing them requires the [[kernel/README]] formal process (CEO + Architect). Conflicts defer to higher-numbered values only with explicit CEO reasoning.
