# Daily SOP — VJSOS

## Morning Ritual (30 min)

1. **Load context** — Read `MASTER_CONTEXT.md`
2. **Check sprint goal** — Confirm today's priority from `WEEKLY_SPRINTS.md`
3. **Classify tasks** — Label each task 1-4 (Phase)
4. **Start Phase 1-2 work first** — docs, research, coding, Android content

## Work Cycle (90 min blocks)

| Block | Phase Priority | Activities |
|-------|---------------|------------|
| Block 1 | Phase 1 | Documentation, planning, research, Git, Obsidian |
| Block 2 | Phase 1-2 | Coding, Android dev, React tools |
| Block 3 | Phase 3 | Blender, Remotion, image gen (slow — batch this) |
| Block 4 | Phase 1 | Session log update, knowledge base |

## Phase 1 First Rule
Always finish Phase 1 work before starting Phase 2. Always finish Phase 2 before Phase 3. Phase 4 = defer or outsource.

## Daily Log
At end of day, append to `sessions/YYYY-MM-DD_DAYN.md`:
- What was completed
- What was blocked
- What phase was worked on
- One lesson learned

## Evening Ritual (10 min)
1. Clean up workspace
2. Commit to Git with clear message
3. Plan tomorrow's top 3 tasks
