# Weekly SOP — VJSOS

## Sprint Cadence (Monday → Sunday)

### Monday — Sprint Planning (60 min)
1. Load `MASTER_CONTEXT.md` + `WEEKLY_SPRINTS.md`
2. Review last sprint: completed / blocked / carried over
3. Set **3-5 sprint goals** (specific, measurable, phase-aware)
4. Break goals → daily tasks with phase labels (1-4)
5. Assign owners (human or AI agent)

### Tuesday-Thursday — Execution
| Day | Focus |
|-----|-------|
| Tue | High-impact Phase 1-2 work |
| Wed | Deep work (content, code, scripts) |
| Thu | Cross-functional, reviews, integration |

**Daily Standup (async, 5 min):**
- What did you complete yesterday?
- What's next?
- Blockers?

### Friday — Sprint Review (60 min)
1. Demo completed work
2. Measure against sprint goals
3. Capture metrics:
   - Videos/scripts produced
   - Code commits
   - Docs updated
   - Blockers resolved
4. Update `CHANGELOG.md`

### Saturday — Retrospective + Next Sprint Prep (45 min)
1. What worked? What didn't?
2. Process improvements → update SOPs
3. Next sprint goal candidates
4. Team health check

### Sunday — Rest / Learning
- Skill development (Blender, prompting, etc.)
- Reading, research, inspiration
- No operational work

---

## Phase-Aware Sprint Planning

| Phase | Sprint Capacity | Rule |
|-------|----------------|------|
| 1 | Unlimited | Always do first |
| 2 | High | Do after Phase 1 |
| 3 | Low (1-2 tasks max) | Batch, schedule intentionally |
| 4 | Zero | Defer/outsource |

---

## Inter-Sprint Handoff

At end of each sprint:
1. Archive completed tasks to `CHANGELOG.md`
2. Carry over incomplete → next sprint
3. Update `WEEKLY_SPRINTS.md` with next sprint plan
4. Brief CEO on strategic implications
