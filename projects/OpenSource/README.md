# Project OpenSource

> VJSOS open source contributions and libraries.

## Mission

Share tools, utilities, and frameworks back to the community — while building brand recognition and contributing to the ecosystem that VJSOS depends on.

## Principles

1. **Open by default** — anything useful to others should be considered for open-sourcing
2. **Clear license** — MIT unless stated otherwise
3. **Documented** — README + examples + CONTRIBUTING.md required
4. **Tested** — CI + basic tests required
5. **Maintained** — issues triaged within 72 hours

## Catalog

| Project | Description | Language |
|---------|-------------|----------|
| vjsos-mdx | Markdown extensions for studio workflows | Python |
| vjsos-agents | AI workforce prompt templates | Markdown |
| vjsos-bash | Shell utilities for content studios | Bash |
| vjsos-render | Blender render farm utilities | Python |

## Process

1. **Proposal:** Submit issue with idea, use case, expected audience
2. **Approval:** CEO + Architect review
3. **Setup:** Create repo, license, README, .gitignore
4. **Release:** Tag v0.1.0, publish
5. **Maintain:** Triage issues, accept PRs, version updates
