# Project Kids Studio — Mystery Makers Club

> Original animated series for kids ages 6–12.

## Mission

Create safe, educational, entertaining animated content that teaches problem-solving, kindness, science, logic, art, and communication — without copyable unsafe actions or manipulative engagement.

## Episode Structure

| Segment | Duration | Purpose |
|---------|----------|---------|
| Cold open | 0–25s | Mystery hook |
| Setup | 25–70s | Present problem |
| Investigation | 70s–2m | 3 clue beats |
| False theory | 2m–2:30 | Funny wrong answer |
| Discovery | 2:30–3:30 | Correct solution |
| Resolution | 3:30–4:30 | Kind action |
| Recap | 4:30–5:00 | Skill learned |
