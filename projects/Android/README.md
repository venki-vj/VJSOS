# Project Android — YouTube Channel

> Android development tutorials for a global audience (India-first).

## Mission

Help developers and creators learn Android development through high-intent, evergreen tutorials — packaged safely and clearly.

## Content Pillars

1. **AI Tools for Android Devs**
   - AI code generation
   - AI UI design
   - AI testing and debugging

2. **Software Tutorials**
   - Android Studio setup
   - Kotlin fundamentals
   - Jetpack Compose
   - Firebase integration
   - Testing and debugging

3. **Device & App Fixes**
   - Crash troubleshooting
   - Battery optimization
   - App errors and recovery

## Episode Structure

| Segment | Duration | Purpose |
|---------|----------|---------|
| Hook | 0-5s | Clear promise of the video |
| Problem | 5-10s | Show the problem |
| Solution | 10s-3m | Step-by-step solution |
| Result | 3m | Show working result |
| Next steps | Last 5s | What to learn next |
