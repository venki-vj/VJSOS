# Project InternalTools

> Software tools built internally by VJSOS — some stay internal, some ship as products.

## Mission

Automate, streamline, and productize the internal workflows of VJSOS. Turn internal utilities into commercial-grade products where there is market demand.

## Tool Catalog

| Tool | Purpose | Stage | Revenue Model |
|------|---------|-------|---------------|
| asset-organizer | Tag and store animation assets | 🟢 Released | Free |
| prompt-manager | Version and track AI prompts | 🟡 Beta | Freemium |
| render-tracker | Track render jobs across nodes | 🟡 Beta | Free |
| storyboard-ai | Generate storyboards from scripts | 🔴 Planning | Freemium |
| subtitle-scout | Auto-transcribe + translate | 🔴 Planning | Subscription |
| episode-planner | 22-step pipeline dashboard | 🔴 Planning | Team plan |
