# VJSOS  🎨🎬💻

> **A studio that scales sustainably.**

VJSOS (VJ Studios / VJ Systems of Software) is a **multi-business-unit content and software studio** built on a **three-layer architecture**:

| Layer | Function |
|-------|----------|
| 🧠 **Brain** | Documentation, planning, knowledge, research |
| 🏭 **Factory** | Rendering, animation, local AI |
| 💾 **Data Center** | Dedicated servers, render farm, AI workstations |

**Founded:** August 4, 2026 by Venkatesh  
**Philosophy:** _Build capability before buying capacity._

## Agent System

VJSOS is designed to work with an **AI workforce** of specialized agents:

| Agent | Role |
|-------|------|
| 🧠 CEO | Strategy, direction, resource allocation |
| 🏗️ Architect | Technical systems, pipeline design |
| 🔍 Research | Market validation, audience insight |
| 📋 Project Manager | Sprint execution, task tracking |
| 🎬 Animation Director | Visual style, 22-agent workflow |
| 🔊 Sound Director | Voice, music, foley, mixing |
| 🛡️ Child Safety | Dedicated child-safety gatekeeper |
| 📜 Rights & Clearance | IP verification, licensing |

All agent prompts are in [`docs/prompts/`](docs/prompts/) — versioned and reusable.

## Phase-Aware Development

| Phase | What | Current Hardware |
|-------|------|------------------|
| **Phase 1 — Brain** | Docs, planning, Git, Obsidian | ✅ 100% |
| **Phase 2 — Software** | Python, React, Android, basic AI | ✅ 90% |
| **Phase 3 — Factory** | Blender-light, Remotion, AI tools | ⚠️ Slow |
| **Phase 4 — Data Center** | Big models, 4K, training | ❌ Deferred |

> **Rule:** Phase 1 → 2 → 3 → 4. Never skip. Phase 4 work is deferred until Phase 3 blocks revenue.
