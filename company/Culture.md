## Communication Norms

- **Async-first:** Prefer documented, versioned, reviewable communication.
- **Written > spoken:** Decisions live in ADRs, not meetings.
- **Clear escalation:** Blockers go to the right agent/owner quickly.
- **Default to public:** Within the org, share completely — knowledge is compound interest.

## Decision-Making

- **Kernel changes:** CEO + Architect approval (immutable; requires formal process). See [[kernel/README]].
- **Technical decisions:** ADR process. See [[governance/DocumentationRules]], [[decisions/README]].
- **Business decisions:** CEO, informed by [[prompts/RESEARCH_AGENT]] research.
- **Content decisions:** Chain of custody via the 22-agent workflow for kids; publisher/SEO for Android.

## Working Style

- **Phase-aware:** Do Phase 1–2 first; run Phase 3 in intentional batches; defer Phase 4.
- **Documentation-as-code:** Docs update with code and decisions — no stale knowledge.
- **No-blame retrospectives:** We fix systems, not people.
- **Continuous learning:** Weekly skill blocks (Blender, prompting, code) per [[docs/sop/DAILY]].

## AI as Employees

AI agents are treated as team members with:
- Missions, responsibilities, inputs/outputs, KPIs
- Versioned prompts (see [[prompts/README]])
- Escalation rules to human leadership
- Equal priority in task tracking

## Rituals & Habits

- **Monday:** Sprint planning (3–5 goals)
- **Friday:** Sprint review + retrospective
- **Sunday:** Rest / learning / reflection
- **Morning:** Load [[docs/MASTER_CONTEXT]], set today's Phase 1–2 tasks

## Psychological Safety

- No blame, no shame, no fear of asking.
- Everyone (human or agent) can raise a concern.
- The Child Safety and Rights agents have absolute authority to block content — by design.
