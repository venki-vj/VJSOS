# VJSOS — Welcome

This is the **VJSOS home vault** for managing the studio's knowledge, documentation, and operations.

## What this vault contains

- **Core documentation** – vision, principles, roadmap, architecture
- **Business units** – Android Channel, Kids Studio, Software Products
- **Execution** – daily SOPs, weekly sprints, session logs
- **AI workforce** – agent prompts, orchestration, workflow
- **Infrastructure** – hardware phases, upgrade triggers
- **Knowledge graph** – wiki-linked documentation

## Getting started

1. Open with Obsidian
2. Load the `MASTER_CONTEXT.md` (recommended first)
3. Follow the `WEEKLY_SPRINTS.md` for planning
4. Use `prompts/` for agent roles
5. Update `sessions/` daily
